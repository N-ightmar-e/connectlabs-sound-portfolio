# 일정 서버와 디스코드 봇 명세

서버로 돌릴 컴퓨터에서 만든다. 이 문서는 상세 페이지(`v2/artmug.js`)가 기대하는 것과 봇이 할 일을 적는다.

## 하는 일

디스코드에서 슬래시 명령으로 가능한 시간을 등록하면, 아트머그 상세 페이지의 "세팅 가능한 일정"에 바로 나타난다.

## 페이지가 읽는 API

`GET <서버 주소>?start=YYYY-MM-DD&days=7`

- CORS: `Access-Control-Allow-Origin: *`(아트머그와 GitHub Pages에서 부른다). `Cache-Control: no-store`.
- 응답(지금 서버와 같은 모양):

```json
{
  "timeZone": "Asia/Seoul",
  "slotMinutes": 30,
  "bufferMinutes": 0,
  "checkedAt": "2026-11-27T05:30:13.255Z",
  "days": [
    { "date": "2026-12-03", "slots": [ { "index": 36, "status": "available", "start": "18:00", "end": "18:30" } ] }
  ]
}
```

- `days`는 `start`부터 `days`일, 날짜 순으로 모두 넣는다. 열린 칸이 없는 날은 `"slots": []`.
- `index`는 그날 0시부터 30분 단위 순번(18:00 → 36). 페이지는 `status === "available"`인 칸만 보여 준다.
- 페이지는 4주 앞까지 한 주씩 부른다.

페이지를 새 서버로 바꾸려면 아트머그 본문의 상자에 주소만 적는다. 코드는 다시 빌드하지 않아도 된다.

```html
<div id="akmong-studio" data-theme="light" data-api="https://새-서버-주소/api/availability">…</div>
```

## 슬래시 명령

| 명령 | 입력 | 하는 일 |
|---|---|---|
| `/가능` | 날짜(12/3, 내일, 금요일), 시작, 끝 | 그 시간을 30분 칸으로 나눠 연다 |
| `/마감` | 날짜, (시작, 끝) | 시간을 주면 그 칸만, 안 주면 그날 전부 닫는다 |
| `/일정` | (주) | 이번 주(또는 고른 주)의 열린 칸을 보여 준다 |
| `/예약` | 날짜, 시작 | 상담으로 확정된 칸을 예약됨으로 바꿔 페이지에서 빠지게 한다 |

- 답장은 명령을 쓴 사람에게만 보이게(ephemeral) 하고, 무엇이 바뀌었는지 한 줄로 말한다. 예: "12월 3일(목) 18:00–23:00, 10칸을 열었습니다."
- 명령은 정해 둔 디스코드 사용자 ID만 쓸 수 있다.
- 작업 원칙(하루 5건까지, 오후 6시부터)에 어긋나는 입력은 막지 않고 답장에 알려 준다.

## 권하는 구성

- Cloudflare Workers 하나에 두 경로: `GET /api/availability`(페이지용), `POST /discord`(디스코드 Interactions). 저장은 Workers KV 또는 D1.
- 디스코드는 Interactions Endpoint URL 방식이라 항상 켜 둔 연결이 필요 없다. 요청 서명(Ed25519)을 반드시 확인한다.
- 비밀값(봇 토큰, 공개 키, 허용 사용자 ID)은 `wrangler secret`으로 넣고 저장소에 두지 않는다.
- 나중에 구글 캘린더를 붙일 때는 `/가능`, `/예약`이 캘린더에도 일정을 만들게 한다.

## 끝났는지 확인

1. `/가능 내일 18:00 20:00` → API 응답의 내일 날짜에 `index` 36~39가 `available`로 나온다.
2. `v2/test/host.html`의 상자에 `data-api`를 넣고 열면 그 네 칸이 보인다.
3. `/마감 내일` → 페이지에서 사라진다.
