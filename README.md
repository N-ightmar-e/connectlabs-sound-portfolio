# connectlabs-sound-portfolio
악몽 Nightmare — 방송·음향 세팅 작업 포트폴리오와 아트머그 상담 안내

- `index.html`, `embed.html`: 지금 아트머그에 iframe으로 걸린 포트폴리오.
- `v2/`: 아트머그 본문에 직접 그리는 새 상세 페이지.
  - `v2/src/`에서 고치고 `node v2/build.mjs`로 `v2/artmug.js`를 만든다.
  - 미리 보기: `v2/index.html`(독립), `v2/test/host.html`(아트머그 흉내, 3,000px 접힘 포함), `v2/variants.html`(시안 셋).
  - 아트머그에 붙일 내용: `v2/paste.html`.
  - 디자인 결정: `v2/DESIGN.md`.
